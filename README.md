# ORBITAL ECHO: BEYOND THE STARS

Prototipo di videogioco 3D space shooter/survival creato con Grok.

## Descrizione
ORBITAL ECHO è un gioco 3D in stile space survival realizzato interamente in HTML + Three.js. Il giocatore controlla una navicella, deve sopravvivere nello spazio, distruggere asteroidi e nemici, gestire lo scudo e accumulare punteggio.

## Tecnologie
- Three.js (r128)
- WebGL / Post-processing (bloom)
- HTML5 Canvas
- Controlli touch + tastiera
- Sistema di salvataggio locale
- Audio integrabile
